##  项目简介

这是一个专为都市悬疑爽剧打造的自动化剧本生成与检索系统。以主角**轩宁**为核心，系统通过“小编剧室”多维校验机制，持续推进紧张刺激的剧情：
* **策划定钩子**：每回精确定制爽点、反转与极限拉扯。
* **写手写正文**：高质量地产出轩宁斗智斗勇、撕开真相的正文章节。
* **审校把关**：多维流量密码评分与安全审查，确保剧情节奏高能、绝不拖沓。

## 📂 核心架构与目录

* **seasons/02_city/**：存放《破局者：都市深渊》的世界观、规则设定及轩宁的章节连载。
* **souls/**：存放轩宁及剧中核心 NPC 的角色档案与实时状态。
* **engine/**：自动化写作、文笔校对与剧情追踪的底层脚本。
